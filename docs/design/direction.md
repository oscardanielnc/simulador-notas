# Design direction

Chosen by Oscar on 2026-10-28 after 4 mockup rounds. Approved mockup: [mockup-v4.html](mockup-v4.html).

| Decision   | Choice                                                                                                                            |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Reference  | https://dribbble.com/shots/27447418-AI-Wellness-Coach-App-Health-Habit-Tracking-UI — big rounded cards, ring gauge, progress bars |
| Color      | ONE hue (purple) in several tones. Darkest = most important (final grade). Red only for grades < 10.5                             |
| Background | White (option A). Rejected: lavender background, dark purple background, multi-pastel cards                                       |
| Borders    | None. Soft shadows. A semi-thick accent border ONLY on the selected element                                                       |
| Real grade | Solid ★ icon in accent purple. Rejected: pink/purple borders, ✨ sparkles (read as AI)                                            |
| Editor     | Fixed bottom sheet with ruler picker, shows only the element's name                                                               |
| Hierarchy  | Final card (filled dark) → criterion cards (very light lavender) → chips (white)                                                  |

History

- 2026-10-28 v1 desktop tree → v2 pastel → v3 single purple, 3 backgrounds → v4 white, no borders, ★.
