# simulador-notas

Mobile app for university students to record their grades per course and simulate their final grade with a slider.

- Product: [docs/product/vision.md](docs/product/vision.md)
- How it is built: [docs/build-plan.md](docs/build-plan.md)

```sh
pnpm install
pnpm start        # Expo dev server
pnpm test
pnpm build:apk    # Android APK through EAS
```
